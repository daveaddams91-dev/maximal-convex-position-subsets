# Maximal Convex Position Subsets

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/rajveersinh-is-dev/maximal-convex-position-subsets/actions/workflows/ci.yml/badge.svg)](https://github.com/rajveersinh-is-dev/maximal-convex-position-subsets/actions)


On the extremal number of maximal convex-position subsets of a planar point set: exact values f(n) for n<=9, a duality theorem, and reproducible computation over all order types.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/maximal-convex-position-subsets.git
cd maximal-convex-position-subsets
python "experiments/check_github_math.py" --help
```
